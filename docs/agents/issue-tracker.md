# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, comment on, label, and close issues using `gh issue`.
- Infer the repository from `git remote -v`.
- Pull requests are not treated as a triage request surface.
- When a skill says "publish to the issue tracker," create a GitHub issue.
- When a skill says "fetch the relevant ticket," read that issue and its comments.
- Wayfinder maps and child tickets use GitHub issues, sub-issues, labels, assignments, and native
  dependencies where available.
